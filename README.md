# 🏢 DQMS - Document & Quality Management System (Frontend)

**DQMS (Document & Quality Management System)** is a comprehensive and modern platform built to streamline document handling, quality assurance, and organizational management processes.  
This **frontend** project provides a robust and user-friendly interface that integrates with a powerful backend system — enabling organizations to define custom roles, manage company documents, and automate workflows with personalized notifications.

---

## 🚀 Key Features

### 🔐 Advanced Role-Based Access Control
- Define **custom roles** dynamically via the admin panel  
- Assign **granular permissions** to each role (view, edit, approve, delete, etc.)  
- Built-in **Super Admin** with full system control  
- Role-driven interface – users see only what they’re authorized to access  

### 🗂️ Document Management
- Comprehensive document type and category system  
- Upload, update, version, and archive documents  
- Assign approvers and reviewers to specific document types  
- Track document history and revision logs  
- Integrated document search and filtering tools  

### 📧 Personalized Email Notifications
- Custom email templates for document updates, approvals, and new role assignments  
- Automated alerts for pending document approvals  
- Personalized user notifications for workflow activities  

### 📊 Quality Management Tools
- Manage quality control records and audits  
- Define company-wide document standards and compliance levels  
- Attach quality reports and related documents to specific records  

### 🌐 Modern UI / UX
- Developed with **React** for a dynamic, responsive experience  
- Built using **Bootstrap** for consistent, modern styling  
- Dark/Light mode support (optional)  
- Optimized layout for enterprise dashboards and workflows  

---

## 🛠️ Tech Stack

- **Framework:** React  
- **UI Library:** Bootstrap 5  
- **State Management:** Context API / Redux  
- **Routing:** React Router  
- **API Communication:** RESTful API integration  
- **Notifications:** Custom email system & in-app alerts
